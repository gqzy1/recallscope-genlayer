# Changelog

## 0.3.0 — 2026-10-23

### Added

- Official CPSC title-search integration with model-aware text ranking, direct official links and source retrieval times.
- Explicitly dated fallback catalogue, with a reproducible refresh command and no silent substitution for live search.
- Multi-notice investigation notebook: up to eight selected notices, independent findings, unchecked coverage and per-notice evidence.
- Follow-up product revisions with fresh request IDs, preserved historical records, changed-input comparison and dimension-label changes.
- Browser persistence, complete investigation JSON exports, cached-provenance labels and exact chain re-verification of saved records.
- Tests for discovery failures, URL allowlisting, multi-notice coverage, changed inputs, record tampering, revision isolation and real DOM workflows.

### Improved

- Larger inspection labels, input text, findings and notes, with responsive investigation controls.
- Edited forms explicitly identify displayed records as unchanged historical results.

### Compatibility

The deployed contract source, address and `recallscope-1` protocol remain unchanged. Investigation grouping and revision links are local; each onchain record still assesses one product against one official notice.

Previous-release comparison baseline: `2f4c85ca72e3a93ce868dfa49c5811e43fd891fb`.
